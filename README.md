# travelmemory-ec2-deployment
Deployment of Travel Memory application on AWS EC2 with load balancing
Technologies Used
MongoDB Atlas
Express.js
React.js
Node.js
AWS EC2
Application Load Balancer
Nginx
PM2
Deployment Steps
1. Backend Setup
Cloned GitHub repository
Installed dependencies
Configured environment variables
Connected to MongoDB Atlas
Started backend using PM2
2. Frontend Configuration
Updated backend URL in frontend
Installed dependencies
3. Reverse Proxy
Configured Nginx to route traffic to backend
4. Scaling
Created two EC2 instances
Deployed backend on both instances
5. Load Balancer
Created target group
Registered EC2 instances
Created Application Load Balancer
